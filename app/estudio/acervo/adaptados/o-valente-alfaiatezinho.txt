— O alfaiate está trabalhando — disse o alfaiate.
— Costurando um casaco e calças — disse o alfaiate.
O alfaiate era um homem muito habilidoso. Ele fazia roupas lindas.

— Uau, que geléia deliciosa! — disse a camponesa.
— Está tão doce e cheirosa — disse a camponesa.
O alfaiate sorriu. — Queria um pouco — disse o alfaiate.
— Para provar o meu trabalho — disse o alfaiate.

— Não, não! — disse a vendedora. — Não dê geléia para um alfaiate!
— É muito caro — disse a vendedora.
A vendedora foi embora, muito irritada.

— Hummm, que gostoso — disse o alfaiate.
— As moscas não gostam — disse o alfaiate.
O alfaiate espantou as moscas com um sopro.

— Contando moscas! — disse o alfaiate.
— Uma por cada cor — disse o alfaiate.
O alfaiate fez uma faixa colorida. — “Sete com um só golpe!” — disse o alfaiate.

— Preciso de coisas para a viagem — disse o alfaiate.
— Um pássaro enroscado — disse o alfaiate.
O alfaiate libertou o pássaro.

— E um gigante na montanha — disse o alfaiate.
— Um gigante muito grande — disse o alfaiate.
O alfaiate decidiu conversar com o gigante.

— Olá, gigante — disse o alfaiate.
— Podemos ajudar — disse o alfaiate.
O alfaiate mostrou a faixa para o gigante.

— Queijo para o gigante — disse o alfaiate.
— Ele gosta de queijo — disse o alfaiate.
O alfaiate pressionou o queijo no gigante.

— Lance o pássaro — disse o alfaiate.
— Para que ele voe alto — disse o alfaiate.
O pássaro voou para longe.

— Vamos para a caverna — disse o alfaiate.
— Para ver os gigantes comerem — disse o alfaiate.
Os gigantes comiam ovelhas assadas.

— Vou destruir a cama — disse o alfaiate.
— Com esta barra de ferro — disse o alfaiate.
Os gigantes fugiram com medo.

— Eu sou um guerreiro forte — disse o alfaiate.
— Todos me temem — disse o alfaiate.
O rei ficou impressionado.

— Casamento e parte do reino — disse o rei.
— Para o alfaiate — disse o rei.
Os soldados não gostaram da ideia.

— A tarefa do alfaiate — disse o rei.
— Derrotar dois gigantes — disse o rei.
O alfaiate foi para a floresta.

— Pedras para os gigantes — disse o alfaiate.
— Eles não resistem — disse o alfaiate.
O alfaiate derrotou os gigantes.

— Confirmo a morte — disse o alfaiate.
— Os gigantes não estão mais — disse o alfaiate.
O alfaiate sorriu.

— Retorno com os cavaleiros — disse o alfaiate.
— E mostro minha força — disse o alfaiate.
Os cavaleiros voltaram com o alfaiate.

— Gigantes mortos e árvores — disse o alfaiate.
— Uma floresta diferente — disse o alfaiate.
O rei ficou muito feliz.

— Pegue o unicórnio — disse o rei.
— Para mim — disse o rei.
O alfaiate pegou o unicórnio.

— Pegue o javali — disse o rei.
— Um javali selvagem — disse o rei.
O alfaiate pegou o javali.

— Filha e metade do reino — disse o rei.
— Para o alfaiate — disse o rei.
O rei deu tudo ao alfaiate.

— A rainha está triste — disse a rainha.
— O marido é tão humilde — disse a rainha.
A rainha planejou algo.

— O escudeiro revela o plano — disse o escudeiro.
— Para a esposa do alfaiate — disse o escudeiro.
O escudeiro contou tudo.

— Casaco e calças — disse o alfaiate.
— Para assustar os criados — disse o alfaiate.
Os criados ficaram com medo.

— Abandonam o rei — disse os criados.
— Por medo — disse os criados.
Os criados foram embora.

— Eu sou o rei agora — disse o alfaiate.
— E governo até o fim — disse o alfaiate.
O alfaiate governou com sabedoria.
