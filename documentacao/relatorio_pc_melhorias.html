2. Diagnóstico: Gargalos para o Projeto de IA

🔴 Crítico — precisa de ação imediata

SSD C: com 15 GB livres. O Windows precisa de pelo menos 20-30 GB livres para funcionar corretamente (página de swap, atualizações, cache do sistema). Abaixo disso o PC pode travar, corromper arquivos ou ter degradação severa de performance. Este é o problema mais urgente, independente de IA.

⚠️ Alto impacto — limita o projeto de IA diretamente

GPU com 6 GB de VRAM. O Gemma 3 4B ocupa ~3 GB e o OmniVoice ocupa ~2,5 GB — juntos somam 5,5 GB, no limite. Isso força o ciclo sequencial (um descarrega antes do outro carregar), que é o motivo pelo qual a Pandora leva 4-5 segundos para responder. Com 12+ GB de VRAM, ambos coexistiriam e a latência cairia para ~1-2s.

💡 Impacto médio — melhora geral do sistema

RAM em 16 GB. Para uso intenso com Ollama + Python + Chrome abertos simultaneamente, 16 GB é suficiente mas justo. 32 GB eliminaria qualquer swapping de memória. Contudo, a placa-mãe H310M limita os slots a 2 (já ocupados com 2×8 GB), então upgrade RAM = trocar os pentes.

ℹ️ Plataforma: dead end

A placa-mãe H310M com LGA 1151 não suporta processadores acima do i9-9900K. Não dá para upgradar para i7-12700 ou Ryzen 7 sem trocar também a placa-mãe e a RAM. Para uma evolução mais completa no futuro, o upgrade de plataforma (CPU + placa-mãe + RAM DDR5) seria a abordagem certa — mas é caro e não é necessário agora para o projeto de IA.

4. Upgrades Recomendados (do mais para o menos urgente)

🔴 URGENTE — SSD NVMe 1 TB (substituir C:)

~R$ 350–420

O SSD atual do sistema (C:) tem apenas 15 GB livres de 238 GB. Isso é crítico: o Windows precisa de swap de memória, cache de atualização e espaço temporário. Abaixo de 20 GB, o sistema começa a engasgar e arquivos podem ser corrompidos. Isso precisa ser resolvido antes de qualquer outra mudança.

Opção recomendada

Kingston NV3 1TB M.2 NVMe PCIe 4.0 — leitura 6.000 MB/s, gravação 4.000 MB/s. Disponível na KaBuM! e Pichau por ~R$ 350–420.

⚠️ Atenção: a placa-mãe H310M tem 1 slot M.2, mas pode ser PCIe 3.0 (não 4.0). O Kingston NV3 PCIe 4.0 funciona em PCIe 3.0 com velocidade menor (~3.500 MB/s) — ainda assim 5× mais rápido que o SATA atual.

✅ Benefícios

  • Resolve o problema crítico de espaço imediatamente
  • Sistema fica 3-5× mais rápido no geral
  • Modelos de IA carregam mais rápido do disco
  • Custo baixo, maior impacto prático do dia a dia
  • Instalação simples (clone do C: para o NVMe)

❌ Contras / Cuidados

  • Precisa migrar o Windows (clonar ou reinstalar)
  • Slot M.2 da H310M pode ser PCIe 3.0 (velocidade reduzida)
  • Não resolve o gargalo de VRAM para IA
  • O SSD antigo (SATA) pode ser reaproveitado como E:

+5× velocidade do sistema operacional +espaço: 1 TB em vez de 238 GB +carregamento de modelos mais rápido

⭐ PRINCIPAL — GPU RTX 3060 12 GB

~R$ 1.800–2.200

Este é o upgrade que transforma o projeto de IA. Com 12 GB de VRAM, o Gemma (3 GB) e o OmniVoice (2,5 GB) coexistem com ~6 GB de folga. Isso permite:

  • Gemma e OmniVoice rodando simultaneamente na GPU
  • Latência da Pandora cai de ~4,5s para ~1,5s
  • Possibilidade de testar modelos maiores (Gemma 12B, LLaVA, Whisper large)
  • A abordagem de streaming Gemma + TTS concorrente — que tentamos e falhou com 6 GB — passaria a funcionar

Por que RTX 3060 12 GB e não RTX 4060 8 GB?

A RTX 4060 8 GB é mais nova mas tem menos VRAM que a 3060. Para jogos, a 4060 vence. Para IA local, VRAM é o que importa — e 12 GB vs 8 GB é uma diferença enorme. A 3060 permite rodar modelos que a 4060 não consegue.

Preços atuais

  • RTX 3060 12 GB — R$ 1.800–2.200 (nova) / R$ 1.200–1.600 (usada no Mercado Livre)
  • RTX 4060 8 GB — R$ 2.500–3.400 (KaBuM!) — mais cara e menos VRAM
  • RTX 4060 Ti 16 GB — R$ 5.860–7.000 (Hardware Barato) — melhor opção mas preço alto
  • RTX 4070 Super 12 GB — R$ 6.149 (Mercado Livre) — top de linha acessível

✅ Benefícios

  • Latência da Pandora: 4,5s → ~1,5s
  • Gemma + OmniVoice simultâneos na GPU
  • Modelos maiores (Gemma 12B, Whisper large)
  • Streaming pipeline passa a funcionar
  • Compatível com PCIe 3.0 da H310M
  • RTX 3060 usada tem bom custo-benefício

❌ Contras / Cuidados

  • Custo: R$ 1.800–2.200 (novo)
  • Verificar se a fonte de alimentação aguenta (mínimo 550W recomendado)
  • RTX 3060 está sendo descontinuada (estoque residual)
  • Plataforma H310M limita a PCIe 3.0 (não PCIe 4.0) — sem perda real para a GPU

⚠️ Verifique a fonte antes de comprar

A RTX 3060 consome até 170W. Se sua fonte for 450W ou menos, pode ser necessário trocar também. Fontes 550W Bronze custam ~R$ 250–350. Se a fonte for 550W+ você está seguro.

💡 OPCIONAL — RAM 32 GB DDR4

~R$ 220–300

A RAM atual de 16 GB é suficiente para o projeto hoje, mas com Ollama + Python + Chrome + VS Code + Estúdio abertos ao mesmo tempo, pode haver pressão de memória. Com 32 GB, o sistema fica mais confortável e elimina qualquer swap de RAM.

Como fazer: trocar os dois pentes atuais (2× 8 GB Crucial DDR4-2400) por 2× 16 GB DDR4-3200. A H310M suporta até DDR4-2666 oficialmente, mas DDR4-3200 funciona em XMP/fallback a 2666 MHz. Custo: ~R$ 220–300 por kit 2× 16 GB.

✅ Benefícios

  • Elimina swap de RAM (melhora fluidez geral)
  • Permite modelos maiores em CPU offload
  • Mais conforto rodando múltiplos apps simultâneos
  • Custo muito baixo

❌ Contras / Cuidados

  • Impacto no projeto de IA é pequeno (gargalo é VRAM, não RAM)
  • Precisa vender/guardar os pentes atuais (os slots estão cheios)
  • A H310M limita a velocidade a DDR4-2666 oficialmente
  • Não resolve nenhum problema atual diretamente

+fluidez geral do sistema impacto moderado no projeto de IA

🔮 FUTURO — Troca de Plataforma Completa

~R$ 2.500–4.000

O i5-8400 na H310M é uma plataforma encerrada. Para evoluir para processadores modernos (i5-13600K, Ryzen 7 7700X) seria necessário trocar CPU + placa-mãe + RAM (DDR5). Isso não é necessário agora para o projeto de IA — o i5-8400 é rápido o suficiente, pois o gargalo é sempre a GPU.

Quando faria sentido

  • Se você quiser rodar modelos em CPU offload (ex: LLMs que não cabem na VRAM) — a velocidade de geração de tokens melhora muito com CPUs modernas
  • Se surgir uma necessidade de mais threads (video encoding, compilação pesada)
  • Como atualização completa do PC para os próximos 5-6 anos

✅ Benefícios

  • Plataforma moderna (PCIe 4.0/5.0, DDR5)
  • CPU com mais threads (Hyper-Threading de volta)
  • Suporte a GPUs futuras sem limitação de PCIe
  • Mais slots de RAM e M.2

❌ Contras / Cuidados

  • Custo alto: ~R$ 2.500–4.000 (CPU + placa-mãe + RAM DDR5)
  • Não resolve o gargalo de VRAM (esse é sempre a GPU)
  • Não é necessário para o projeto atual
  • Melhor esperar próxima geração AMD/Intel (2026/2027)

impacto pequeno no projeto de IA atual recomendado deixar para depois
