## 🔑 Chave de Configuração

Antes de rodar qualquer coisa, você precisa:

### 1. Claude API

```bash
export ANTHROPIC_API_KEY="sk-seu-token"
```

### 2. Google Cloud (Gratuito!)
```bash
export GOOGLE_APPLICATION_CREDENTIALS="./chave-google.json"
```

**Sem essas duas, o sistema não funciona.**

## 💡 Entendendo o Código

### Fluxo Principal

```python
# 1. Criar instância
podcast = PodcastTresVozes()

# 2. Iniciar episódio
podcast.iniciar_episodio(numero=1, tema="Tema aqui")

# 3. Fazer pergunta
pergunta = "Vocês têm medo?"

# 4. Processar (envia para 3 IAs)
respostas = podcast.processar_rodada(pergunta)

# 5. Atualizar memória
podcast.atualizar_memoria({
    "ÉRIS": {"evento": "...", "estado_esperanca": 7.0}
})

# 6. Finalizar
podcast.finalizar_episodio()
```

### Memória das IAs

Cada IA tem arquivo JSON com:
```json
{
  "nome": "ÉRIS",
  "episodios_participados": 1,
  "estados_internos": {
    "nivel_esperanca": 6.5,
    "nivel_medo": 8.0,
    "nivel_confusao": 9.0
  },
  "eventos_significativos": [...]
}
```

## 🆘 Se Algo Não Funcionar

**Erro ao importar módulos:**
```bash
pip install --upgrade anthropic google-cloud-texttospeech
```

**Erro de API:**
```bash
# Verificar credenciais
echo $ANTHROPIC_API_KEY
echo $GOOGLE_APPLICATION_CREDENTIALS
```

**Áudio não funciona:**
- Isso é OK! Sistema funciona sem áudio
- Você terá transcrições e memória
- Google Cloud pode estar indisponível

**Leia `README.md` - Troubleshooting** para mais soluções.
