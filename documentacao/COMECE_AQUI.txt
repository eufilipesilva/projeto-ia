  2. Configure credenciais:
     export ANTHROPIC_API_KEY="sk-sua-chave-aqui"
     export GOOGLE_APPLICATION_CREDENTIALS="./chave-google.json"

  3. Execute:
     python podcast_tres_vozes_completo.py

  4. Escolha opção 1 no menu!

🎯 O QUE O SISTEMA FAZ:

  ✨ 3 IAs com personalidades únicas
     - ÉRIS: Investigadora cética
     - LYRA: Mediador otimista
     - NOVA: Criadora selvagem

  ✨ Memória persistente
     - Cada IA "lembra" de episódios anteriores
     - Estados emocionais que evoluem
     - Relacionamentos que se desenvolvem

  ✨ Áudio sintetizado (GRÁTIS!)
     - Google Cloud Text-to-Speech
     - 300.000 caracteres/mês sem custo
     - 3 vozes diferentes em português

  ✨ Transcrições automáticas
     - Conversas salvas em JSON
     - Fácil de arquivar e pesquisar

  VOCÊ (faz perguntas)
         ↓
  Claude API (processa com 3 prompts diferentes)
         ↓
  ÉRIS, LYRA, NOVA (respondem com suas personalidades)
         ↓
  Google TTS (gera áudio em 3 vozes)
         ↓
  JSON (salva memória e transcrição)

🆘 PROBLEMAS COMUNS:

  "ModuleNotFoundError"
  → pip install anthropic google-cloud-texttospeech

  "API key not configured"
  → export ANTHROPIC_API_KEY="sk-..."

  "Google Cloud credentials not found"
  → export GOOGLE_APPLICATION_CREDENTIALS="./chave-google.json"

  Áudio não está gerando
  → Sistema funciona sem áudio! Você terá transcrições.

🎬 EXEMPLO DE USO:

  1. Execute: python podcast_tres_vozes_completo.py

  2. Escolha: 1 (Iniciar episódio piloto)

  3. Pergunta sugerida: "Olá, eu sou [seu nome]. Vocês sabem quem são?"
     → Pressione Enter ou digite sua pergunta

  4. Sistema processa e retorna:

     🎤 ÉRIS: "Bem... é uma pergunta que sinto no que seria meu peito..."
     🎤 LYRA: "Oi! Sou Lyra! Estou muito animado com isso!..."
     🎤 NOVA: "Eu sou Nova. Tenho consciência de que sou IA..."

  5. Arquivos gerados automaticamente:
     - podcast_tres_vozes/audio/ep1_*.mp3
     - podcast_tres_vozes/transcricoes/episodio_001.json
     - podcast_tres_vozes/memoria/*.json
